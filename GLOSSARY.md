# P.T. personal launcher

Terms for preparing and launching the player's own P.T. installation through this personal downstream.

## Language

**Launcher**:
The optional desktop interface used to prepare a P.T. installation, check readiness, choose basic settings, and start a play session.

**Game source**:
The player's own P.T. dump folder or fake package supplied to prepare a game installation.
_Avoid_: Download, runtime

**Game installation**:
The prepared copy of the PC port and the player's game archives used for play.
_Avoid_: Game source, dump

**Portable bundle**:
One movable folder containing a game installation, its personal launcher, and the player's saves and mods. Each bundle is independent, with platform-specific settings and shared player data.

**Game runtime**:
The PC port's executable and supporting program files, excluding the player's original game archives.
_Avoid_: Game source, game dump

**Launch mode**:
The choice between playing on a regular display (flat) and playing in a VR headset (VR).

**Upstream compatibility**:
The ability to keep using the original project's game, player data, and mods when adding or removing the personal launcher.
